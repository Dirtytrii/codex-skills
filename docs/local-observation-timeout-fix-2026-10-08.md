## 故障证据与修复

旧采集器使用定长 buffered read，完整 JSON 已到达但 stdin 保持打开时，3.3 秒后仍未退出；关闭 stdin 的命令测试无法覆盖该场景。真实宿主日志不足以确认用户截图中的两次超时都由该机制触发，不能将复现条件等同于已证实的宿主根因。

修复使用有 1 MB 上限的原始管道分片读取，完整 JSON 即开始处理，不依赖换行或 EOF，支持跨分片 UTF-8。当前短生命周期 hook 进程内部设置 1.5 秒等待预算，空输入、残缺输入或慢采集到期均返回惰性 `{}`；超时可能丢失观测，不代表零活动。保留已经验证的 Windows 命令封装和外部 3 秒上限，不修改模型或增加常驻服务。
